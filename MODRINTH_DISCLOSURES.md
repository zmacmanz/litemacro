# Modrinth Content Disclosures

Suggested answers for the current Litemacro build:

| Disclosure | Suggested setting | Why |
| --- | --- | --- |
| Contains advertisements | Off | Litemacro does not show ads by default. Turn this on only if you add sponsored/promotional content. |
| Contains paid features | Off | Litemacro does not sell paid features in the mod. |
| Contains telemetry | On | The optional marketplace sends upload, download, like, macro metadata, and a local uploader/liker ID to Supabase. |
| Contains derivative content | On if Pathmind or any other project code/assets are copied or adapted | Leave this off only if all included code/assets are original to Litemacro or properly licensed dependencies. |
| Photosensitivity warning | Off | No flashing lights or patterns are intentionally included. |
| External system interactions | On | Litemacro reads/writes local macro/config files, imports/exports macro files, can contact Supabase for marketplace features, and can send Discord webhooks when configured. |

Use the public `PRIVACY.md` URL from GitHub as the privacy policy link after the repository is uploaded.
