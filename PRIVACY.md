# Litemacro Privacy Policy

Effective date: September 4, 2026

This policy explains what data Litemacro uses and when it is sent outside your computer.

## Summary

Litemacro is a Minecraft client mod for building and running macros. Most macro data stays on your computer. Network activity only happens when you use online features such as the marketplace or a Discord webhook component.

Litemacro does not use Discord OAuth sign-in and does not collect Discord access tokens or refresh tokens.

## Local Data

Litemacro stores data locally in your Minecraft folder, including:

- Macro files and macro settings.
- Keybind settings.
- Marketplace download files.
- A random local marketplace uploader ID used to limit uploads.

This data is used by the mod so your macros and settings keep working between game sessions.

## Marketplace Data

The optional marketplace uses a Supabase backend. When you browse, upload, download, or like marketplace macros, Litemacro may send or receive:

- Macro name.
- Author name entered by the uploader.
- Macro description and tags.
- Minecraft version and Litemacro version.
- Macro JSON data needed to recreate the macro.
- Download and like counts.
- A random local uploader or liker ID generated by the mod.

The local uploader/liker ID is not a Discord account and is not a Minecraft login token. It is used to limit uploads and prevent the same local install from liking the same macro repeatedly.

Do not upload macros that contain private information. A macro can contain text you entered into components, including commands, server IPs, notes, item names, Discord webhook URLs, or messages.

## Discord Webhooks

Litemacro includes a Discord Notification component. If you configure that component, the mod sends the configured message to the Discord webhook URL you entered when the macro reaches that component.

Webhook URLs are private. Do not share macros publicly if they contain a private webhook URL.

## Data Sharing

Litemacro does not sell personal data.

Marketplace data is sent to the configured Supabase project so marketplace features can work. Discord webhook messages are sent to Discord only when you configure and run a Discord Notification component.

## Removing Marketplace Uploads

Marketplace uploads are managed by the Litemacro project owner. To remove a marketplace upload, contact letgio through the official Litemacro support channel and include the macro name and author name shown in the marketplace.

## Changes

This policy may be updated when Litemacro changes how online features work.
