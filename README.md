# Litemacro

Litemacro is a Fabric client mod for Minecraft Java Edition. It adds a drag-and-drop macro builder, macro slots, component-based logic, marketplace sharing, notes, and in-game macro controls.

## Source Layout

- `versions/mc26.2` - Litemacro for Minecraft 26.2.
- `versions/mc1.21.11` - Litemacro for Minecraft 1.21.11.
- `versions/mc1.21.1` - Litemacro for Minecraft 1.21.1.
- `wiki` - user guide and component reference.
- `database` - Supabase SQL setup for the Litemacro marketplace.
- `config` - example marketplace configuration.
- `test-macros` - example/test macro files.

## Build

Open PowerShell in the version folder you want to build, then run:

```powershell
.\gradlew.bat build
```

Examples:

```powershell
cd versions\mc26.2
.\gradlew.bat build
```

```powershell
cd versions\mc1.21.1
.\gradlew.bat build
```

The built jar appears in that version folder under `build\libs`.

## Use

- Press `B` in Minecraft to open Litemacro.
- Use the main Litemacro menu to select macro slots, assign macro keybinds, import/export macros, and open the marketplace.
- Open the builder to place components on the canvas, connect outputs, add notes, and configure component settings.
- Use `Run` and `Stop` from the builder or macro menu to test a macro.
- Save often; the builder also has auto-save support.

Command aliases:

```text
/litemacro
/lm
/macrobuilder
/macro_builder
```

## Marketplace

The marketplace is optional. It uses Supabase as the backend and no longer uses Discord OAuth sign-in.

Users can:

- Browse published macros.
- Upload a selected macro.
- Download a marketplace macro into the current macro slot.
- Like a marketplace macro.

Uploads are limited by a local uploader ID generated by the mod. The backend default limit is 5 uploads per local user ID.

Marketplace setup files:

- `database/litemacro-supabase-marketplace.sql`
- `database/litemacro-supabase-like-fix.sql`
- `config/litemacro-marketplace.properties.example`
